## 项目概述

本仓库保存 SMMG3050 课程项目的代码、实验记录、图表、报告源文件和展示材料。

项目是一份端到端的工业数据分析研究：提出一个有明确工业背景的问题，完成数据准备，建立并比较模型，如实评估，并解释结果的含义与适用边界。

课题尚未确定。课程允许使用公开数据集（Kaggle、天池等）或自拟工业问题。我们会在开始建模前锁定数据集，并把选择理由记录在 [`docs/00-topic-selection.md`](docs/00-topic-selection.md)。

## 仓库结构

```text
.
├── configs/            # 实验配置（YAML/JSON），一个实验一个文件
├── data/
│   ├── raw/            # 原始数据，不入库
│   ├── interim/        # 中间清洗数据，不入库
│   └── processed/      # 建模用数据，不入库
├── docs/               # 按评分表组织的文档与计划
├── figures/            # 报告和幻灯片使用的图
├── literature/         # 期中文献、阅读笔记与方法迁移评估
├── notebooks/          # 探索性分析，按 01_、02_ 编号
├── reports/            # 报告与展示源文件
├── scripts/            # 入口脚本：下载数据、跑实验
├── src/                # 可复用代码，供 notebook 与脚本导入
├── requirements.txt
└── README.md
```

约定：notebook 只做探索；可复用的逻辑放进 `src/`；任何要写进报告的数字，都必须通过 `scripts/` + `configs/` 产生，保证能复现。

## 快速开始

环境暂时不锁定。数据集和技术栈确定后：

1. 创建并激活虚拟环境。
2. 在 `requirements.txt` 中写死版本号。
3. 把实际安装命令补到本节。

```bash
git clone git@github.com:Euclidea24/smmsg3050-industrial-data-analytics.git
cd smmsg3050-industrial-data-analytics

python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

不要添加未锁定版本的依赖。只用于探索的包要么不放进共享环境，要么同样锁版本。

## 课题与数据集选择

决策记录：[`docs/00-topic-selection.md`](docs/00-topic-selection.md)。候选按以下标准筛选：

1. **工业相关性** — 对应真实的过程、设备、产品或运营环节，而不是给通用机器学习基准硬贴一个工业标签。
2. **获取与许可** — 数据可合法获取，代码可公开，不必再分发受限数据。
3. **标签质量与泄漏风险** — 目标变量是独立测量的，不是由其他列直接推出来的。
4. **可行性** — 第一天就要能跑出有意义的基线，整条流水线必须在 11-28 前完成。
5. **可解释性** — 结果能向非机器学习背景的听众讲清楚。
6. **可复现性** — 队友或助教能拿到同一份数据并重跑。

## 数据规则

- `data/raw/` 的原始数据可以入库；同一份数据只提交一份（压缩包或解压文件，不要两份都放）。派生数据和个人信息不入库。
- 凭证一律不入库。
- 在 [`data/README.md`](data/README.md) 记录数据集名称、来源链接、许可证、获取日期、校验和与署名。
- 只切分一次数据，且要在任何“需要学习参数”的预处理（缺失值填补、标准化、编码、特征选择）之前完成；这些步骤只在训练集上拟合。
- 最终模型冻结之前不要查看测试集，并记录测试集被评估过几次。
- `data/raw/` 保持只读；清洗结果写到 `data/interim/` 或 `data/processed/`。

## 可复现性

- 报告中的每张图、每张表都必须由已提交的脚本与配置重新生成。
- 固定随机种子，并写进配置文件。
- 在 [`docs/08-reproducibility.md`](docs/08-reproducibility.md) 记录 Python 版本、依赖版本和硬件。
- 目标是用一条命令从原始数据复现最终结果。

- 完整流程见 [`CONTRIBUTING.md`](CONTRIBUTING.md)。
- 每个改动都开 PR，作者不自行合并到 `main`。
