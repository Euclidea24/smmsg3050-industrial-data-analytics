# 文献与期中方法迁移

本目录收集中期论文分享阶段的文献信息、阅读笔记，以及“是否把期中方法迁移到期末数据”的评估记录。

**PDF 原文可以提交。** 只放组内期中论文，统一放在 `literature/papers/`；文件名用 `<第一作者姓>-<年份>-<短标题>.pdf`，单篇尽量不超过 10 MiB。仓库是公开的，不要放未获授权或与课程无关的资料。

## 这个目录回答两个问题

1. 期中论文里哪些方法适合作为期末项目的候选？
2. 把某个方法套到另一份数据上，需要改什么、代价多大、值不值得在 11-28 前做？

## 怎么加一篇论文

1. 复制 `notes/_template.md` 为 `notes/<第一作者姓>-<年份>.md`，例如 `notes/smith-2024.md`。
2. 填元数据和笔记；结论要能指到论文的页码或章节。
3. 在 `reading-list.md` 加一行。
4. 如果是迁移候选，在 `method-transfer.md` 填一行评估。

## 目录

```text
literature/
├── README.md            # 本页
├── reading-list.md      # 所有论文的总表
├── method-transfer.md   # 期中方法 → 期末数据的迁移评估
├── notes/
│   ├── _template.md     # 笔记模板
│   └── <author>-<year>.md
└── papers/
    └── <author>-<year>-<short-title>.pdf
```

## 写作规则

- 只写你读过的内容；区分“论文原话”“你的推断”“待验证”。
- 引用页码或图表编号，避免二手转述。
- PDF 放 `papers/`，笔记里不要大段复制原文；引用页码或图表编号即可。
- 笔记语言中英文均可，但论文标题、作者、DOI 保留原文。
- 笔记里的数字必须来自论文原文；外部统计量要注明来源。
