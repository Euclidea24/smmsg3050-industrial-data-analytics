# Method Transfer Evaluation

**Status:** no papers collected yet; fill the Candidates table after the first reading round.

**Question:** can a method from a midterm paper be applied to a different dataset for the final project?

## Decision rule

Transfer only if all four hold:

1. **Assumptions match** the new data: unit of analysis, label type, temporal or group structure.
2. **Adaptation is feasible** within the remaining time (target: one day to a first result).
3. **Evaluation is comparable**: same metric, split, and baseline as the final project.
4. **Expected gain beats risk**: the method is likely to beat a simple baseline, or it answers a rubric item better.

If any item is unknown, record it as an open question instead of assuming.
