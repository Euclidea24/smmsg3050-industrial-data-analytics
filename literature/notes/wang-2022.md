- **Link / DOI:** https://doi.org/10.1080/00401706.2021.2020171
- **Owner:** —

## Problem and setting

Manufacturing processes collect many process variables (temperature, pressure, speed, vibration) that are converted into process features (mean, variance, natural frequency). The goal is to automatically rank these features by their dependency with a quality variable, to support root-cause analysis, process design improvement, sensor placement, and quality monitoring (p. 384).

The paper argues an automatic ranking must satisfy two rules (p. 384):

1. **General dependency** — the measure must capture linear *and* nonlinear relationships between a feature and the quality variable, including cases where a feature affects the *variance* of the quality variable rather than its mean.
2. **Diversity rule** — a feature should only be prioritized if it is not redundant with features already deemed strongly related to the quality variable. This ensures one feature per root cause is promoted, so a small number of leading features covers all potential root causes.

## Method

- **Inputs:** feature matrix `X ∈ R^{n×p}` (n products, p features) and quality variable `y ∈ R^{n×1}`.
- **Outputs:** a ranking (order) of the p features.
- **Training objective / algorithm:**
  - Assign a non-negative weight `β_i` to each feature and define a β-weighted ℓ1 distance between samples: `d_β(x,x') = Σ_i β_i |x_i − x'_i|`.
  - This yields a weighted sample distance covariance `V²_{n,β}(X,y) = d_nᵀ β` and weighted sample distance correlation `R²_{n,β} ∝ d_nᵀ β / √(βᵀ F_n β)`, where `d_n` holds feature–y distance covariances and `F_n` holds pairwise feature–feature distance covariances.
  - Solve the sparse optimization (p. 387): maximize `d_nᵀ β` subject to `βᵀ F_n β = 1` (relaxed to `≤ 1`), `Σ β_i ≤ c`, `β_i ≥ 0`. This is a conic quadratic (second-order cone) program, solvable efficiently by interior-point methods.
  - Features are ranked by the order they enter the active set `J(c) = {i : β_i(c) > 0}` as the sparsity parameter `c` increases (regularization path via bisection search or warm-start; Algorithms 1–2, pp. 387–388).
- **Key assumptions:** features are scaled so `V_n(x_i,x_i) = 1`; the method captures pairwise *main effects* and cannot detect interaction effects between features (weighted ℓ1 metric is not of strong negative type).

## Data used in the paper

- **Simulation (5 settings, pp. 390–391):** independent and dependent features, nonlinear and variance-only relationships, 100–1000 samples; compared against six baselines — Lasso, adaptive Lasso, LMG (relaimpo), random forest (RF), LZZ distance-correlation screening, YR stepwise distance correlation.
- **Case study 1 — solar cell epitaxy (p. 392):** 24 process features, 50 samples, quality variable = solar conversion efficiency (SCE); validated on 7 follow-up samples.
- **Case study 2 — lithography overlay (pp. 393–394):** simulated testbed, 1000 wafers, 842 overlay features (21×21 grid × 2 components), quality = sum of shift magnitudes across four root-cause regions.

## Evaluation and main results

- **Simulation:** SpaDC ranks dependent features ahead of independent ones under nonlinearity and variance effects (like YR/LZZ), unlike linear-model methods (Lasso, LMG) and RF. In Settings 4–5 SpaDC uniquely satisfies the **diversity rule** — it prioritizes features independent of the leading features (pp. 390–391).
- **Case study 1:** SpaDC ranks feature `X1` first; only `X1` shows an abrupt shift in its control chart on the 5 shifted follow-up samples, confirming the ranking (p. 392).
- **Case study 2:** SpaDC's top-4 features each map to one of the four independent root-cause regions. Lasso/adaptive Lasso fail due to nonlinearity; LZZ and RF each miss one root cause within their top-6 (p. 394).

## Strengths and limitations

- **Strengths:** captures general (nonlinear + variance) dependency; enforces diversity; convex formulation with a unique solution (Proposition 1); theoretical guarantees that dependent features are ranked first (Propositions 3–4); validated on real semiconductor data.
- **Limitations:** cannot identify interaction effects between features; computation of `d_n`/`F_n` is O(n log n) per element (parallelizable) and each `β(c)` solve is O(p³ log(1/ε)); no closed-form regularization path (uses bisection/warm-start approximation).

## Relevance to our project

Directly relevant to industrial data analytics. Feature ranking/selection is a core preprocessing and model-selection step. If our final dataset involves ranking or selecting process features, SpaDC offers a nonlinear, diversity-aware alternative to Lasso/RF feature importance. Transfer candidate is marked **?** until the dataset is locked.

## Transfer check

- **What would change for our data:** need a univariate quality variable `Y`; compute pairwise distance covariances (`d_n`, `F_n`) for our features; require a second-order cone solver.
- **What must stay the same:** the two ranking rules (general dependency + diversity); the convex optimization formulation; the assumption that main effects dominate interaction effects.
- **Minimum experiment to test it:** run SpaDC against Lasso / RF importance on our dataset and check whether the top-ranked features cover distinct root causes and are interpretable.
